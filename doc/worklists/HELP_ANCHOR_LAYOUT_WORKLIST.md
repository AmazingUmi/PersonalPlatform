# 问号锚点布局

## 目标

每个问号与它解释的标题、字段或操作处在同一不换行的横排中。问号不再单独成行，也不与另一个问号贴在一起。浮层开关、双语正文、可见警告和业务逻辑保持不变。

## 已接受约束

- 标题/字段与问号的组合使用 `inline-flex` 且 `flex-wrap: nowrap`。问号 `flex: none`。文字在自己的 `min-width: 0` 盒子里换行。外层容器可以整组换行。
- 问号不进入 `h1`/`h2`/`h3`、会激活输入的 `label`、链接或按钮，从而保留这些元素的无障碍名称。
- WebDAV「连接设置」问号放在「WebDAV 目录地址」标签旁，不放在 Connection 导航页签旁。自动备份、手动备份方式各自紧挨自己的标签。
- 窗口级说明用 `PixelWindow` 的可选 `titleHelp`，作为标题元素的兄弟，避免被 `actions` 推到标题栏另一端。空状态说明用 `EmptyState` 的可选 `help`，与空状态标题同排。

## 锚点

设置页标题、系统窗口「应用」项、界面语言字段；数据管理与 WebDAV 窗口标题；合并备份与备份历史标题；目录地址、自动备份、手动备份方式字段；登录窗口标题；应用中心标题、卡片名称、自定义窗口标题；仪表盘标题，以及「编辑布局」/「编辑模式」；任务、笔记、资产、专注、时钟页面标题和任务详情标题；各空状态标题；获取日期、重复、城市时区、标签；2048 标题与最高分组件标签。

时钟、任务、笔记、资产、专注的仪表盘组件本身没有问号。只有 2048 最高分组件有一处，且留在卡片正文内，不放进卡片标题栏。

## 非目标

不改 HelpPopover 的开关、定位和门户行为，不改 Core、后端、迁移或用户数据。
